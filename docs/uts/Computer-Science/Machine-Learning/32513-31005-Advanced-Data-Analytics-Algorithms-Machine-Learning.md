# 32513 31005 - Summary

These notes follow the first five modules of **Advanced Data Analytics Algorithms, Machine Learning**. They move from the definition of a learning problem to the criterion, model family, and algorithm used to construct a working predictor.

| Module | Main concepts | Notes |
| --- | --- | --- |
| 1. What Is Machine Learning? | Learning from examples, generalization, and when machine learning is useful | [Read Module 1](./module_1.md) |
| 2. Statistical Learning Framework | Data distributions, hypotheses, criteria, and learning algorithms | [Read Module 2](./module_2.md) |
| 3. Learning Criterion and Loss Functions | Regression and classification losses, information theory, structured outputs, and empirical risk | [Read Module 3](./module_3.md) |
| 4. Hypothesis Design and Unsupervised Models | Basis functions, neural networks, kernels, representation learning, and generative models | [Read Module 4](./module_4.md) |
| 5. Training Algorithms and Gradient Optimization | Closed-form and data-based models, gradient descent, and adaptive optimizers | [Read Module 5](./module_5.md) |

The module pages contain the detailed explanations, equations, examples, and comparisons. Later modules can be added to this course as their notes are prepared.
